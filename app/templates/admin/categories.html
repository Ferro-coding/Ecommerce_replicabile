Aggiungi Categoria

Per aggiungere categorie, usa la shell Python: 

from app import create_app, db
from app.models.product import Category

app = create_app()
with app.app_context():
    cat = Category(
        name='Nome Categoria',
        slug='nome-categoria'
    )
    db.session.add(cat)
    db.session.commit()
